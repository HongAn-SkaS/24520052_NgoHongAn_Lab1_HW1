# Project Rules
- Vanilla HTML5, modern CSS, ES6+ JS only.
- No jQuery, Bootstrap, Tailwind, external CDN.
- Semantic HTML over div. 0 div for layout.
- const by default, let only if reassigned.
- Never render unescaped user input with innerHTML.
- Mobile-first: 375px baseline.
- Atomic commits. No monolithic PRs. No one-shot AI.
